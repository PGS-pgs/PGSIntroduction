Why

Grasshopper 没毛病，就是这三下有点磨手

都不是大问题，但一天要重复两百次，就成了大问题。

PAIN 01

删一根线，要精确点到那 2 像素

线一多、一密、一反向，鼠标就在贝塞尔曲线上"抖针"。想一次清掉七八根？只能挨个点、挨个删，还不能 Ctrl+Z 整批回来。

PAIN 02

定义一放大，就不知道自己在哪儿

找那个"上游三层的 Number Slider"，滚轮狂奔半分钟，跑过头再滚回来。Rhino 原生的 Zoom Selected 是盲跳，没有落点预览。

PAIN 03

连线永远是：松手 → 找口 → 再按 → 再拖

刚放下一个 Divide Curve，下一个动作一定是回头上游找输出口。这条链路没有任何快捷键，纯靠手腕往返。

The Kit

三个工具，各管一段

全部以 GH_AssemblyPriority 挂载，只读叠加，不 Patch 不劫持原生 Render，卸载即干净恢复。

TOOL 01

PGS_WireDelete 框选 + 点选整批 Undo

在画布空白处拖一下，框过的线全部亮成双层蓝；点一下，就近吸附最贴近鼠标的那根。回车删、Esc 退，一次 Ctrl+Z 整批回来。

  • 高亮路径直接取 GH_Painter.ConnectionPath —— 和你屏幕上那条线是同一条。正向、反向回钩、折线、电气线，像素级零偏移，支持与 WiresRenderer 共存自动跟随线型。
  • 命中检测对贝塞尔 打平采样 + 线段距离，不是包围盒近似；容差可调，密集区也不会误伤隔壁线。
  • 撤销走 GH_WireAction 按 Target 去重：一个输入端只记一条 Undo 记录，十根线一次撤回，不会重放半截。
  • 文档切换 / 对象删除 / Ctrl+Z 后自动 剪枝失效引用，不留鬼影高亮、不持已释放对象。
DragClickEnterEsc
TOOL 02

PGS_MiniMap 缩略全图缓动转场

中键一按，弹出整张定义的缩略图：灰块是全图，橙块是匹配到的目标电池，红虚框是你此刻正看着的那块画布。点橙块，镜头三次方缓动飞过去，落点稳稳居中。

  • 先看见再跳：不是盲跳 Zoom Selected，飞之前就知道落在哪儿、周围还有什么。
  • cubic ease-out 转场（≈15ms/帧），空间感不断线，大脑不会"丢帧重定位"。
  • 批量模式：同名电池全亮橙，点任意一个都跳，跳完继续接着上一段没画完的线——拖拽状态不中断。
  • Esc / 点空白 = 干净取消，自动回滚拖拽状态，不留半截悬空线头。
MMBClick 橙块Esc
TOOL 03

PGS_TabConnect Tab 上游Shift+Tab 下游

线拖到一半、还没松手，按一下 Tab：弹出当前参数类型兼容的上游输出口列表，选一个直接接上，手不用离开键盘区。反向找下游用 Shift+Tab。

  • 类型感知过滤：只列能真接上的口（含隐式转换），不会给你一个红了再撤回。
  • 距离 + 拓扑双排序：近的、同 Group 的、同层级的排前面，绝大多数时候第一项就是你要的。
  • 与 MiniMap 打通：候选不在视口内 → 先飞过去 → 自动续上没松手的那根线。
  • 走 GH_UndoRecord 正规入栈，和原生连线一次 Ctrl+Z 一起撤，不留脏状态。
TabShift + TabEnterEsc

Install

三条路，挑一条

装完在 Grasshopper → File → Special Folders → User Objects 同级 Libraries 里能看到 PGS_Tools.gha，重启 Rhino 即生效，无需任何设置。

① 最省事：Rhino 的包管理器（推荐）

Rhino 8 里打开 _PackageManager 搜 PGS Tools 一键装；或 Grasshopper 内置 Yak 命令行：

# Grasshopper 菜单栏 → Solver → Yak → 输入：
Install-Package PGS_Tools

# 升级
Update-Package PGS_Tools
# 卸载（干净恢复原生行为，无残留）
Uninstall-Package PGS_Tools
② 手动装：下 .gha 丢进 Libraries

点上方下载最新版 → 解压 → 把 PGS_Tools.gha 拖进 Grasshopper 窗口，或复制到：

# Rhino 7 / 8 (Windows)
%APPDATA%\Grasshopper\Libraries\

# Rhino 8 (.NET 7 专用目录，若上面不生效放这里)
%APPDATA%\Grasshopper\Libraries8\

# Rhino 6
%APPDATA%\Grasshopper\Libraries\

# 首次加载若被拦：右键 .gha → 属性 → 解除锁定 → 重启 Rhino
③ 开发者：源码编译

需要 dotnet 8 SDK + Rhino 8，脚本会自动找到 Rhino 安装路径并输出双 Target 成品到 out/：

git clone https://github.com/<REPO>.git
cd pgs-tools
dotnet restore
dotnet build -c Release        # → out/net48/PGS_Tools.gha + out/net7.0-windows/PGS_Tools.gha

# 只想要某一个插件？编译时关开关：
dotnet build -c Release -p:EnableMiniMap=false -p:EnableTabConnect=false
Changelog

改了什么，一条条挂着

v1.0.0 2026-11-20LATEST
  • 首个公开版。三件套齐发：WireDelete / MiniMap / TabConnect。
  • WireDelete：高亮由手搓贝塞尔改为直取 GH_Painter.ConnectionPath(p0, p3, right, left) —— 反向回钩、Electric 大弧线、折线圆角全部像素级对齐原生，并自动跟随 WiresRenderer 当前线型。
  • WireDelete：命中检测改为 path Flatten() 后逐段点到线段距离，与 WiresRenderer 的 DistanceToWire 同源，点选零偏差。
  • WireDelete：Undo 改 GH_WireAction 按 Target 去重，N 根线一次撤回；补文档切换 / 对象删除剪枝，杜绝鬼影高亮。
  • MiniMap：cubic ease-out 转场（默认 420ms，可在 PGS_TabConnectSettings.TransitionTime 调）；批量模式命中后保留 PGS_DragState.IsLocked，续连不中断。
  • TabConnect：类型兼容过滤 + 距离/拓扑双排序；Esc 全链路回滚，不留悬空线头。
  • 已知限制：Cluster 内部连线不参与框选；Mac 版仅 WireDelete 可用。
v0.3.2 2026-11-08
  • 修：缩放/平移后框选矩形与贝塞尔不在同一坐标系导致的整体偏移（框选统一锁 Canvas 空间，仅绘制时投回 Client）。
  • 修：GH_WireAction 构造顺序错误导致 Ctrl+Z 只回来一半 —— 改为先全量快照再统一 RemoveSource。
  • 优：DistanceToSegment 去掉 Math.Pow，hover 每帧少几十次浮点幂运算。
v0.2.0 2026-10-19

  • 新增 PGS_DragState 冻结/锁态机，解决"跳完视图线头掉了"的老问题。
  • WireDelete 加 6px 外发光双层描边，密集区可辨识度大幅提升。
